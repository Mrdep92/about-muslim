# About Muslim

Aplikasi Android berbasis Jetpack Compose yang menyediakan informasi dan fitur seputar agama Islam, seperti jadwal shalat, Al-Qur'an, dan edukasi keislaman.

## Fitur Utama
- **Beranda**: Ringkasan informasi harian dan ayat pilihan.
- **Jadwal Shalat**: Estimasi dan pengingat waktu ibadah harian.
- **Al-Qur'an**: Membaca dan mempelajari firman Allah.
- **Tentang Islam**: Edukasi dan informasi seputar keislaman.

## Arsitektur & Teknologi
- **UI Framework**: Jetpack Compose (Material3)
- **Bahasa**: Kotlin
- **Target SDK**: Android 14 (API level 34)
- **Minimum SDK**: Android 7.0 (API level 24)
- **Build System**: Gradle dengan Kotlin DSL
- **Java Version**: JDK 17

## Cara Menjalankan Project
1. Clone repositori ini.
2. Buka project menggunakan Android Studio (versi Ladybug atau yang lebih baru).
3. Sinkronkan Gradle (`Sync Project with Gradle Files`).
4. Jalankan aplikasi pada Emulator atau Perangkat Android fisik.
